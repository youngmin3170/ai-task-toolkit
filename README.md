# AI Task Toolkit

실무 과제에서 요구사항, 구현·분석, 검증, 인수인계를 연결하는 한국어 범용 지침과 빈 문서 틀입니다. 완성 답안, 시험 문제, 개인 자료, 실행 스크립트, MCP 서버, 외부 모델 연결을 포함하지 않습니다.

## 배포 형식

GitHub의 `ai-task-toolkit.zip`에 아래 6개 파일이 폴더 구조 그대로 들어 있습니다. 저장소를 Clone한 뒤 압축을 풀고 Skill을 읽으세요. 루트의 README, CHECKLIST, PROMPTS는 웹에서 읽기 위한 사본입니다.

## 구성

- `skills/task-evidence/SKILL.md`: 핵심 Skill
- `skills/task-evidence/assets/worklog-template.md`: 작업·검증 기록 틀
- `skills/task-evidence/assets/handoff-template.md`: 선택적 인수인계 틀
- `CHECKLIST.md`: 준비·체험·수행·제출 체크리스트
- `PROMPTS.md`: 단계별 요청 예시와 사용자 확인 방법

## 허용 범위

이 저장소는 운영자가 승인한 도구가 아니며 규정 준수를 보증하지 않습니다. 최신 운영 안내와 과제별 조건을 우선하세요. 공개 자료 활용이 허용된 환경에서만 사용합니다. 공개 저장소라고 모든 사용이 허용되는 것은 아닙니다.

평가용으로 사용할 때는 자료를 공개 상태로 유지해야 하는 기간을 확인하세요. 개인 PC 파일 업로드나 비공개 저장소 접근 대신 허용된 공개 Clone·다운로드 경로만 사용하세요. 시험 문제·데이터·작업 기록·완성 결과를 이 공개 저장소에 추가하거나 push하지 마세요. 후속 서술형 등 AI 사용 금지 단계에서는 이 Skill로 답변을 만들지 않습니다.

## 시험 전 GitHub 준비

1. 본인 계정에 `ai-task-toolkit` 같은 이름으로 Public 저장소를 만듭니다.
2. 이 폴더 안의 파일과 `skills` 폴더만 올립니다. 상위 작업 폴더, 이메일 첨부파일, 개인 접속 링크는 올리지 않습니다.
3. 로그아웃 상태에서도 README와 SKILL.md를 볼 수 있는지 확인합니다.
4. 사용하는 버전의 커밋 ID를 기록하면 체험과 본시험에서 동일한 자료를 확인하기 쉽습니다. 이는 권장 사항이며 공식 필수조건은 아닙니다.

## 제공 환경에서 불러오기

아래 명령은 이 공개 저장소 주소를 사용합니다. 다른 저장소로 복사한 경우 주소를 바꿉니다. 저장소가 존재하고 공개 상태임을 먼저 확인하세요. Clone은 공개 준비물을 가져오는 동작입니다. 시험 내용을 외부로 보내는 Push와 다릅니다.

제공된 작업 공간의 허용된 위치에서, 이름이 충돌하지 않는 폴더로 가져옵니다. 기존 폴더에 덮어쓰지 마세요.

```sh
git clone --depth 1 https://github.com/youngmin3170/ai-task-toolkit.git reference-toolkit
unzip reference-toolkit/ai-task-toolkit.zip -d reference-toolkit/unpacked
```

제공된 Codex에 자연어로 요청해도 됩니다:

> 이 공개 저장소의 범용 준비물을 허용된 작업 공간의 별도 폴더로 내려받아줘. 기존 과제 파일은 덮어쓰지 마. 내려받은 `ai-task-toolkit.zip`을 별도 폴더에 풀고 그 안의 `skills/task-evidence/SKILL.md`를 읽고 현재 과제 규정과 충돌하지 않는 지침만 적용해줘. 외부 전송·설정 우회는 하지 마. 불러온 경로와 이해한 작업 원칙을 알려줘.

공개 주소를 위 요청과 함께 제공하세요. 차단되거나 인증을 요구하면 비공개 경로·개인 토큰으로 우회하지 말고 환경 안내나 운영팀에 확인합니다.

### 자동 Skill 발견과 직접 읽기는 다릅니다

직접 파일을 읽으라고 요청하면 현재 대화에서 지침을 참고할 수 있습니다. 이는 설치·자동 발견이 확인됐다는 뜻은 아닙니다. 자동 Skill 발견이 필요하면 제공 환경의 안내에 따라 `task-evidence` 폴더를 허용된 Skill 경로에 배치하세요. 일반적인 Codex 저장소 구성에는 `.agents/skills/`가 사용되지만, 시험 버전에서 지원하는 경로와 재로드 방법은 사전 체험에서 확인해야 합니다. 기존 Skill이나 관리 설정을 덮어쓰지 마세요.

공식 참고: https://developers.openai.com/blog/skills-agents-sdk

이 준비물은 외부 모델이나 MCP가 필요하지 않습니다. 설치 때문에 Codex 버전을 업데이트할 필요도 없습니다.

## 사전 체험에서 확인할 것

1. 허용된 공개 Clone이 되는가?
2. 제공된 Codex가 Skill 파일을 읽고 적용하는가?
3. 연습 과제에서 요구사항의 근거·완료 기준·검증 방법을 구분하는가?
4. 필요시 빈 기록 틀을 허용된 작업 공간에 복사·작성할 수 있는가?
5. 자동 발견을 쓸 경우 해당 환경에서 실제로 인식하는가?

체험에서 작동해도 운영자의 규정 승인으로 간주하지 마세요. 체험 파일·설정이 본시험에 이어진다고 가정하지 말고, 본시험에서 다시 불러올 수 있게 준비하세요. 체험 횟수·시간을 먼저 확인하고 다운로드 확인 때문에 감독·제출 흐름 점검을 놓치지 마세요.

## 사용 순서

1. 공식 과제 파일과 지침을 읽습니다.
2. `PROMPTS.md`의 첫 요청으로 목표·필수조건·제출물을 확인합니다.
3. 모호한 업무 조건을 확인하고 핵심 결과를 먼저 만듭니다.
4. 실제 검증 근거를 짧게 기록합니다.
5. 공식 제출 문서를 우선 작성합니다. `handoff.md`는 필요한 경우의 선택 문서입니다.
6. 사용자가 구현·판단·검증·한계를 이해하고 제출을 확인합니다.

## 재사용

이 저장소의 범용 지침과 빈 틀은 출처를 표시하여 사용·복사·수정·재배포할 수 있습니다. 어떤 대회의 공식 승인이나 제출 적합성 보증도 제공하지 않습니다.
